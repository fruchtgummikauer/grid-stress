# 03.4 — Two-Series Comparison Views

Status: draft
Branch: `feature/*` off `main`
Deliverable: the two-series comparison section of `notebooks/01_eda/team-EDA.ipynb`
Depends on: [03-combined-cherry-picked-eda.md](03-combined-cherry-picked-eda.md) and
[03.1-setup.md](03.1-setup.md) — `time_series`, `period_mean` and `style_timeseries` are assumed
to exist. Sits alongside, and assumes the reader has already seen,
[03.3-univariate-and-time-structure.md](03.3-univariate-and-time-structure.md)'s per-series
plots.

## Goal

Port the tagged plots from `EDA-magc.ipynb` and `EDA-robert.ipynb` that compare two series
directly on one axis (`grid_load` vs. `residual_load`, or `solar` vs. wind), and decide, for each,
whether it adds something the per-series views in
[03.3](03.3-univariate-and-time-structure.md) do not — rather than treating every "duplicate"-
tagged two-series chart as an automatic keep.

## Scope

### IN

- Four plots (Behaviour 1–4 below), each answering "how do these two series move together"
  rather than "what does this one series look like."

### OUT

- `EDA-magc.ipynb`'s weekly-mean and monthly-mean `grid_load` + `residual_load` overlay charts
  (its cells 15 and 17, tags `keep, duplicate`) — dropped as redundant with
  [03.3](03.3-univariate-and-time-structure.md) Behaviour 1's per-series `period_mean` panels,
  which already cover both series at both resolutions.
- Calendar-structure heatmaps (`EDA-magc.ipynb`'s hour × weekday heatmaps) —
  [03.5-calendar-structure-heatmaps.md](03.5-calendar-structure-heatmaps.md).

## Behaviour

1. `grid_load` and `residual_load` daily-mean overlay on one axis (source: `EDA-magc.ipynb` cell
   13, tag `keep`). Daily resolution is not covered anywhere in
   [03.3](03.3-univariate-and-time-structure.md) (which only reaches weekly/monthly via
   `period_mean`), so this is additive rather than a duplicate.
2. `grid_load` hourly (raw) + weekly-mean + monthly-mean overlay on one axis, using
   `style_timeseries` (source: `EDA-robert.ipynb` cell 15, tags `combine, expand with other
   features, for streamlit / interactive range, combine with timeline (...)`). Kept alongside
   [03.3](03.3-univariate-and-time-structure.md) Behaviour 1's single-resolution `grid_load`
   panel, not in place of it — the two answer different questions: how far hourly noise sits from
   the aggregates, versus the clean trend itself.
3. `grid_load` and `residual_load` seasonal average as a grouped bar chart by meteorological
   season (source: `EDA-magc.ipynb` cells 19–20, tag `keep, duplicate`). Kept alongside
   [03.3](03.3-univariate-and-time-structure.md) Behaviour 3's `seasonal_plot` view: a plain
   season-to-season level comparison is a different question from year-over-year shape, so both
   stay.
4. Monthly-mean `solar` and `wind_total` (`wind_on + wind_off`, derived at plot time, not
   persisted) overlay on one axis (source: `EDA-robert.ipynb` cell 31, tags `combine with other
   features, modelling, feature engineering cross correlation`), built via `period_mean`, never
   `.resample()`.

## Data

`wind_total = time_series["wind_on"] + time_series["wind_off"]`, computed inline for Behaviour 4
and not added as a persisted column.

## Edge cases

- **`period_mean`, not `.resample()`.** Every monthly/weekly aggregate in this section goes
  through `period_mean` so the partial opening/closing periods are dropped consistently with the
  rest of the notebook.
- **These are additions, not replacements.** Behaviour 1–4 are each kept specifically *alongside*
  an existing per-series or seasonal view because they answer a genuinely different question —
  this section is not a second copy of [03.3](03.3-univariate-and-time-structure.md).
- **The dropped magc overlay charts.** `EDA-magc.ipynb` cells 15 and 17 are tagged `keep,
  duplicate` in the source notebook, but the team's explicit decision was to drop them as
  redundant once the per-series view exists — do not restore them without revising this spec.

## Acceptance criteria

- [ ] All four behaviours appear, each on `time_series` via the shared `period_mean` helper.
- [ ] `EDA-magc.ipynb`'s weekly-mean and monthly-mean two-series overlay charts (cells 15, 17) do
      **not** appear anywhere in the notebook.
- [ ] Behaviour 4's `wind_total` exists only as a local variable inside its plotting cell, not as
      a column on `time_series`.
- [ ] Monthly/weekly aggregates in this section use `period_mean`, not `.resample()`.

## Out of bounds

- `EDA-magc.ipynb`'s dropped weekly/monthly two-series overlay charts.
- Calendar-structure heatmaps, single-event plots, ACF/PACF, STL, ramps, or the context appendix —
  see [03.5](03.5-calendar-structure-heatmaps.md)–[03.7](03.7-context-appendix.md).
- Everything [03-combined-cherry-picked-eda.md](03-combined-cherry-picked-eda.md) rules out
  globally.
